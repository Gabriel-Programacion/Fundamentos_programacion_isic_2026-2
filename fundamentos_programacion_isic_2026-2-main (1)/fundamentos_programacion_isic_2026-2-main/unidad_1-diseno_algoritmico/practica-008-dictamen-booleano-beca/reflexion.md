# Reporte de Reflexión y Autoevaluación

## 1. Retos y Dificultades Encontradas
El reto fue combinar dos condiciones diferentes (promedio y créditos) usando operadores lógicos dentro de una misma variable booleana. Me confundía un poco si debía usar la conjunción `Y` o la disyunción `O`. Lo resolví leyendo bien el enunciado que decía que se debían cumplir ambos requisitos al mismo tiempo.

## 2. Errores Cometidos durante la Depuración
Al ejecutar paso a paso me salió un error de tipos de datos porque declaré la variable `creditosAprobados` como Real en lugar de Entero. La corrección aplicada fue cambiar su declaración a Entero para que coincidiera con el tipo de dato que se estaba leyendo.

## 3. Conclusión Técnica
Aprender a construir expresiones lógicas compuestas sin usar estructuras de control ayuda a simplificar el código, permitiendo obtener dictámenes o validaciones lógicas directamente en una asignación secuencial.
